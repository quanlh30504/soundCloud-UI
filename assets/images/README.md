# Auth Screen Images

Please add the following images to this directory for the new auth screens:

1. `welcome.png` - Image for the Welcome screen (size approximately 350x350px)
2. `login.png` - Image for the Login screen (size approximately 220x200px)
3. `signup.png` - Image for the SignUp screen (size approximately 325x110px)

You can use images from the Login-UI-React-Native folder as reference or create your own.

## Reference Images Location
The reference images can be found in the Login-UI-React-Native project:
- `d:\soundCloud-UI\Login-Ui-React-Native\assets\images\wl.png` (for welcome.png)
- `d:\soundCloud-UI\Login-Ui-React-Native\assets\images\loginimg.png` (for login.png)
- `d:\soundCloud-UI\Login-Ui-React-Native\assets\images\signupimg.png` (for signup.png)
